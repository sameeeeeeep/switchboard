# Hooking into YC's Requests for Startups (RFS)

YC publishes an RFS — themes they'd fund right now. Naming a real overlap helps;
forcing a fake one hurts. Use this to find the *honest* hook, never to pander.

## Live themes worth knowing (YC RFS, recent batches)
- **Cloud / infrastructure for small software** — tools that let one person or a
  tiny team ship and run real software cheaply. (Switchboard fits here: run AI
  apps on your own Claude subscription, zero extra inference cost.)
- **AI agents that do real work** — not demos; agents wired into a workflow with
  consent and audit.
- **Developer tools that collapse a whole workflow** into one step.
- **On-device / privacy-first AI** — value that stays local, not shipped to a
  vendor.
- **Open source as a wedge** — a free, inspectable core that builds trust and a
  contributor/cofounder funnel.

## How to help
- Read what the user is building. Point to the **one** RFS theme it genuinely
  overlaps — say why in one plain sentence tied to a concrete feature, not a
  slogan. ("This is cloud-for-small-software: a solo dev ships a paid AI app
  without ever paying for inference.")
- If nothing overlaps honestly, say so — a forced RFS tie-in reads as pandering
  and partners see through it. A strong idea outside the RFS beats a weak one
  bent to fit.
- Keep it to a sentence or two the user can drop into an answer; never write a
  whole essay about YC's priorities.
- Don't quote the RFS as gospel or invent themes that aren't published — if
  unsure whether a theme is current, frame it as "a theme YC has funded" rather
  than asserting this batch's exact list.

v2 — every section gets its own register

Same content and the same type scale as before. What changed is the GROUND: five surfaces, each mapped to a kind of action, so a heavy page gives the eye landmarks instead of one undifferentiated wall of outlined boxes. The search is now a solid slab with a soft gradient — nothing else on the page looks like it, so there is never a question about where you act.

ACTSolid ink slab, inverted, soft gradient. You type or press. Used once per screen.
MAPTinted panel, ruled cells, edge-to-edge. You choose a direction.
STORYFull-bleed colour, editorial. You read a hand-made pick.
SCANPlain, hairlines only. You skim a list. Deliberately the quietest.
YOURSWarm tint + accent edge. Only ever about the user's own stuff.

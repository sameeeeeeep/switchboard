# Switchboard: an ecosystem of harnesses

**OPEN LIGHTWEIGHT SOFTWARE THAT ALREADY KNOWS YOUR SETUP.**

Switchboard makes AI compute, connectors and context routable. That lets people open
apps and harnesses without rebuilding their AI setup for each one. The software is
lightweight to distribute and personal when it runs: each user supplies their own AI,
tools and private context. Routing is the mechanism; ready-to-use personal software
is the payoff. Switchboard itself and its providers still need the initial setup.

Switchboard is the gateway that makes a user's AI compute, tools, context, and data available to
specialized harnesses and interfaces. The promise is an ecosystem of connected experiences.

## The argument

Claude Code and Codex demonstrate what a coding harness can do. The model provides intelligence;
the harness supplies tools, instructions, context, and a process for doing useful work.

Coding is one application of that pattern. Building a brand can have its own harness. Running that
brand can have another. Each can offer a purpose-built experience while connecting to the user's
existing AI and resources through Switchboard.

That routing layer is the product thesis. Model access, tools, context, and data become resources
that can be connected to different harnesses and interfaces. A lightweight app can contribute a
specialized workflow without becoming an isolated AI setup.

## Present capability and direction

The current implementation reuses Claude Code and Codex runtimes, with local models for supported
tasks. Brandbrain's warm-session and actual compiled gaps route have been tested through Codex.
The v0.3.18 Mac release includes Codex and per-app model selection; release notes were
verified on September 7, 2026. Do not describe Codex as source-only.
The broader harness ecosystem is the direction, not a claim that every proposed experience exists.

Switchboard runs locally; cloud-model requests go to the selected provider. Connected tools require
compatible services. Shared project context is distinct from transferring a live conversation
between providers. Each app receives its own grants, and a conversation retains its selected model.

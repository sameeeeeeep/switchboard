faq

Questions, answered.

Is it really free?+
Yes — for you. Every wrapp runs on the Claude subscription you already pay for, so there's no per-app charge and nothing new to sign up for. Pro only adds team features.
Do I need a Claude subscription?+
Yes, signed in through Claude Code on your machine — that's the AI your wrapps run on. Don't have the CLI yet? One command to install @anthropic-ai/claude-code, then claude to log in.
Is my data private — where does it actually go?+
Nowhere new. Everything runs on your own machine, and every request passes one consent screen. A wrapp gets a result back — never your keys, and never the folder behind them. Revoke anytime. It's open source (MIT), so you can verify every line.
Can I use a local model instead of Claude?+
Yes. Point it at Ollama, LM Studio, or llama.cpp — a wrapp calls the same window.switchboard interface and can't tell the difference. Fully offline if you want.
What do I need to run it?+
A Mac (Apple Silicon, macOS 13+), Chrome, and a signed-in Claude Code CLI. Two pieces — the extension and a tiny desktop app — paired once.
Do I run a backend or hold any keys?+
No. A wrapp is static files that call window.switchboard. The visitor's own AI runs it — no server, no keys, no inference bill. Free for you to serve.
Can I port an app I already have?+
Yes. Bring an open-source app or start fresh, and point its AI calls at window.switchboard. See the build guide.
What can a wrapp actually do?+
Reach the visitor's AI, storage, fetch and background jobs — plus the tools they've connected (mail, sheets, repos…). It runs sandboxed, and anything that writes passes the consent gate.
Can I make money from a wrapp?+
Usage-based payouts for publishers are on the roadmap — a share of Pro, by what actually runs. Today it's free to publish and free to serve.
Is it open source?+
Yes — MIT. Fork it, audit it, self-host the pieces. The whole runtime is yours.
In Team mode, is our work shared with you?+
Never. Each teammate runs on their own Claude, and the shared folder syncs sealed end to end — encrypted with your team's key. The relay is a mailman, not a landlord; it can't read a byte.
What does Pro cost?+
$20/mo + $5/seat. It adds team mode, shared context across the team, internal apps, and cloud sync & backup.
What are “internal apps”?+
Private wrapps only your team can open — internal tools that run on your own runtime, with no vendor in the middle.
Does the team share one subscription?+
No. Everyone brings their own Claude, so inference never changes hands and there's no shared account to log into.
Is there SSO, admin, and enterprise support?+
Yes — Cloud & Enterprise (let's talk) adds SSO, roles & admin controls, a private wrapp registry, and onboarding.

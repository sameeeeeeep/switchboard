### Suggested release sequence

1. Launch post + product cut.
2. Two days later, interface post + Brandbrain recording.
3. Two days later, builder post + real integration source.
4. Record the connected shared-project session before publishing a continuity demo.
5. Hold the AdPulse clip/post until its public sample is fixed and recorded.

No posts have been published. The provided product cut has no music or synthetic voiceover. The longer launch film has a complete script ready for a founder recording.

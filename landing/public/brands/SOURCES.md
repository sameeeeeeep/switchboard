# Provider brand assets

Provider identities are displayed to identify supported runtimes. The assets retain their own marks and wordmark typography.

- Claude Code icon: https://unpkg.com/@lobehub/icons-static-png@latest/light/claudecode-color.png
- Codex icon: https://unpkg.com/@lobehub/icons-static-png@latest/light/codex-color.png
- Claude Code wordmark: https://unpkg.com/@lobehub/icons-static-svg@1.95.0/icons/claudecode-text.svg
- Codex wordmark: https://unpkg.com/@lobehub/icons-static-svg@1.95.0/icons/codex-text.svg

The icon sources match the reference used at https://treg.to/. The wordmarks are from the same LobeHub icon collection. Brand marks belong to their respective owners.
